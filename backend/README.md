# Bank Management System

Academic banking simulation built with Java, Spring Boot, JPA/Hibernate,
a MySQL-compatible database, React, and TypeScript.

## Technology Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA / Hibernate
- MySQL JDBC Driver
- MariaDB for local development
- React
- TypeScript
- Vite
